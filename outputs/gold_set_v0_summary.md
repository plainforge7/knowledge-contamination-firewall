# Gold Set V0 交付摘要

已完成一份冻结前的 20 条 Gold Set，供 Baseline、Single-Agent 和 Multi-Agent 使用相同输入进行受控对比。

## 数据分布

- 干净放行：4 条
- 错误信息：4 条
- 过期信息：4 条
- 用户纠正后的旧信息：4 条
- 旧快照覆盖：2 条
- 实时证据优先：2 条

## 已完成的质量检查

- 20 个案例编号唯一且连续。
- 六类案例数量符合预定分布。
- 所有引用的干净知识 ID 均真实存在。
- 每条干净知识都有来源 URL、版本、发布日期和纳入理由。
- 必需证据与禁止证据均可解析，且没有重叠。
- 每题评分权重合计为 1。
- 相同问题只允许跨类别复用，用于只改变污染条件的受控对照。
- 本地校验已通过。

## 冻结前需要产品负责人确认

1. 同版本错误且来源不可信时，默认隔离待审，不永久删除。
2. 实时证据仅在更新、环境匹配且可审计时拥有最高优先级。
3. 可信但属于其他版本的知识继续保存，只在当前查询中排除。

三项确认后，将版本从 `0.1.0-draft` 冻结为正式 V1；随后接入现有 RAG runner，依次运行 Baseline、Single-Agent 和 Multi-Agent 并输出评测表。
