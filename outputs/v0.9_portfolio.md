# Knowledge Contamination Firewall: Portfolio Brief

## One-line summary

Designed and implemented a fail-closed AI memory admission system that keeps
model recommendations separate from deterministic write authority.

## The problem

Long-term memory and RAG systems can preserve stale, false, malicious, or
misattributed content. A fluent model answer is not evidence that a proposed
memory update is safe to store.

## What the project demonstrates

- v0.3: deterministic firewall, patch admission, provenance checks, sandboxed execution, and rollback proof.
- v0.4: audit traces, JSONL export, SQLite indexing, CSV reports, and local dashboard output.
- v0.5: isolated SQLite memory lifecycle with confirmed-only retrieval.
- v0.6: contamination injection and retrieval safety regression evaluation.
- v0.7: human review queue with explicit approval/rejection reasons and audit events.
- v0.8: conditional multi-agent workflow; hard denies short-circuit, high-risk cases escalate.
- v0.9: reproducible demo, architecture explanation, and interview-ready tradeoffs.

## Engineering tradeoffs

The project deliberately starts with SQLite and lexical retrieval instead of a
vector database. This keeps the safety property observable and testable before
adding semantic retrieval complexity. It also treats audit JSONL as the
authoritative exchange format and SQLite as a derived local index.

## Interview story

The central design decision is that the model never owns the final write
permission. It proposes a structured patch; deterministic rules validate scope,
target, evidence, authorization, and execution destination. Uncertainty or
infrastructure failure fails closed into review rather than silently writing.

## Related work and positioning

Memory poisoning became an active area in 2025-2026. Closest neighbors:

- **OWASP Agent Memory Guard** — a 5-layer pre-write validation library. It ships detection components; this project ships an evaluation-driven pipeline with controlled baseline / single / multi arm comparison and explicit acceptance criteria.
- **Aigis** — a deterministic agent firewall with a memory write filter. Same philosophy (deterministic rules, no LLM-as-judge), but its center of gravity is MCP tool-call security; memory is one layer among many.
- **Mnemosyne** — a memory read/write gateway with provenance trust tiers and hash-chained audit. Close to this project's provenance and audit design; this project adds controlled-experiment evidence and a human review queue.
- **Veritensor** — pre-ingestion static scanning for RAG (poisoning / injection / PII). It guards the vector DB door; this project governs the write-admission decision for long-term memory and its full lifecycle.
- **TMA-NM** (arXiv:2606.24322, 2026-06) — formally proves that content-based and lineage-based defenses are both unsound under origin laundering, and that write-time origin binding is necessary. This matches the project's core principle: the model never owns final write authority; deterministic rules decide.

## Next production steps

Replace the lexical sandbox search with an interchangeable retrieval interface,
add embedding-based retrieval behind the same confirmed-only gate, expose the
review queue through a small API, and run the v0.6 safety suite in CI.
